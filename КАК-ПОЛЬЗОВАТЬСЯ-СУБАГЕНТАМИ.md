# Как пользоваться субагентами в этом проекте

Эти файлы уже подключены к проекту `basis-mvp-v184` — отдельный Vite-проект
для них создавать не нужно, они работают с уже существующим кодом.

## 1. Проверь, что Claude Code видит субагентов

В терминале, в папке проекта (`basis-mvp-v184`, там же, где `index.html`):

```
claude
/agents
```

Должны отобразиться 5 субагентов: `geometry-engine`, `furniture-rules`,
`ui-configurator`, `export-cutting`, `code-reviewer`.

Если не отобразились — проверь, что папка называется ровно `.claude/agents`
(латиницей, с точкой в начале) и лежит прямо в `basis-mvp-v184/`, а не внутри
какой-то другой вложенной папки.

## 2. Как это работает

Ты общаешься с обычной (главной) сессией Claude Code — это и есть
оркестратор, его правила описаны в `CLAUDE.md`. Он сам решает, когда
делегировать задачу субагенту, судя по описанию (`description`) каждого из
них — каждый субагент работает в своём изолированном контексте и возвращает
только итог, не засоряя основной диалог. Можно и явно попросить, например:

> "Делегируй субагенту geometry-engine: добавь предпросмотр текстуры декора
> ЛДСП на боковины в 3D-сцене."

## 3. Важно — этот проект НЕ на Vite и не использует npm

`index.html` открывается двойным кликом прямо с диска — Three.js и SheetJS
подключены через CDN. Если увидишь совет "запусти `npm install`" или
"добавь `import`/`export`" — это ошибка, для этого проекта так делать не
нужно (см. раздел «Стек» в `CLAUDE.md`).

## 4. Мебельный skill

Правила конструирования корпусной мебели (ЛДСП, присадка, Blum/Hettich) уже
лежат в `.claude/skills/konstruirovanie-korpusnoy-mebeli/SKILL.md` рядом с
агентами и в `ПРАВИЛА-КОНСТРУИРОВАНИЯ.md` в корне проекта — субагент
`furniture-rules` рассчитан на то, что прочитает их сам, ничего
дополнительно подключать не нужно.

## 5. С чего начать

Проект уже рабочий (v184) — не проси оркестратора «развернуть базовый
проект» заново, это откатит всё уже сделанное. Формулируй задачи как
доработки, например:

> "Разбей задачу между субагентами по правилам из CLAUDE.md: добавь в
> engine.js поддержку стеклянных фасадов (Этап 2 по roadmap), проверь через
> furniture-rules, обнови 3D и чертёж через geometry-engine, прогони
> code-reviewer."
