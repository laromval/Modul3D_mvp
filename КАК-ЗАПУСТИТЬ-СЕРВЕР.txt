ДОСТУП С ТЕЛЕФОНА И ДРУГИХ УСТРОЙСТВ
====================================

Если server.cmd не запускается и Windows пишет
«Эти файлы невозможно открыть. Параметры безопасности Интернета
не позволили открыть один или несколько файлов» —

это не ошибка программы. Windows помечает всё, что скачано из интернета,
и запрещает запускать такие файлы. Метка снимается в два клика.


СПОСОБ 1 (правильный) — снять метку с архива ДО распаковки
----------------------------------------------------------
1. Правой кнопкой по скачанному файлу basis-mvp-vXX.zip → Свойства.
2. Внизу вкладки «Общие» поставить галочку «Разблокировать» и нажать ОК.
   (Если галочки нет — метки уже нет, переходите к способу 2.)
3. Распаковать архив заново. Все файлы выйдут уже разблокированными.


СПОСОБ 2 — снять метку с самого server.cmd
------------------------------------------
Правой кнопкой по server.cmd → Свойства → галочка «Разблокировать» → ОК.
То же самое сделать для server.ps1.


СПОСОБ 3 — вообще без server.cmd
--------------------------------
Откройте папку проекта в проводнике, щёлкните по адресной строке,
наберите powershell и нажмите Enter. В открывшемся окне введите одну строку:

    python -m http.server 8080

Если Python не установлен, попробуйте:

    npx --yes http-server -p 8080

Адрес компьютера в сети посмотрите командой:

    ipconfig

Нужна строка «IPv4-адрес», например 192.168.1.50.
На телефоне открывайте http://192.168.1.50:8080/


ЧТО ДАЛЬШЕ
----------
- Телефон и компьютер должны быть в одной сети Wi-Fi.
- При первом запуске Windows спросит разрешение сети — разрешите
  для ЧАСТНОЙ сети.
- Закрыли окно сервера — доступ выключился.
- Пока сервер работает, страницу может открыть любой в этой же сети.
