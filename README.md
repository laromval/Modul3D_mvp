# Базис — MVP параметрического конструктора мебели

Этап 1 (MVP) по ТЗ: один тип изделия (прямой корпусный шкаф), базовые параметры,
3D-визуализация в реальном времени, деталировка и спецификация с экспортом в Excel.

## Как запустить

Просто откройте `index.html` двойным кликом — он откроется в браузере по умолчанию.
Сборщик (Vite/Webpack) не нужен: это обычные классические `<script>`-файлы
(без ES-модулей), поэтому файл работает прямо с диска (`file://`), без
локального сервера.

Нужен доступ в интернет (Three.js и SheetJS подключаются через CDN при
открытии страницы).

Если по какой-то причине двойной клик не откроет файл в браузере — запустите
локальный сервер и откройте `http://localhost:8080`:

```bash
cd basis-mvp
python3 -m http.server 8080
```

## Что внутри (соответствие архитектуре из ТЗ, п.4)

- `src/engine.js` — **Parametric Core Engine**: единственный источник истины.
  Строит список деталей (геометрия + поля деталировки) из параметров шкафа.
- `src/catalog.js` — **Material & Hardware Library**: справочник декоров ЛДСП,
  ХДФ, кромки, фурнитуры и крепежа с ценами.
- `src/specification.js` — **Specification + Costing Module**: считает
  спецификацию (материалы, кромка, фурнитура, крепёж, итоговая стоимость)
  напрямую из деталировки — без ручного дублирования данных.
- `src/viewer.js` — **3D Viewer**: рендерит те же детали в Three.js.
- `src/export.js` — **Export Module**: выгрузка деталировки и спецификации
  в `.xlsx` (SheetJS).
- `src/app.js` — **UI/UX Layer**: панель параметров, вкладки деталировки и
  спецификации, единая точка пересчёта `recompute()`.
- `src/sketchAI.js` — распознавание эскиза шкафа через Claude Vision (см. ниже).

Изменение любого параметра слева мгновенно пересчитывает 3D-модель,
деталировку и спецификацию — все три результата берутся из одного вызова
`buildModel()`.

## Что реализовано (MVP, Этап 1 из ТЗ)

- Габариты Ш×В×Г, толщина корпуса и задней стенки, выбор декора ЛДСП и ХДФ.
- Секции (произвольное число): полки, ящики, фасад (глухая дверь на 1/2
  створки или открытая секция без фасада).
- Цоколь или ножки.
- Тип присадки (конфирмат / минификс / шкант) — влияет на расчёт крепежа.
- Деталировка со всеми обязательными полями из п.6 ТЗ, с автосуммированием
  одинаковых деталей.
- Спецификация по 4 разделам из п.7 ТЗ + итоговая стоимость.
- Экспорт деталировки и спецификации в Excel.
- **Расчёт координат присадки и экспорт для ЧПУ** — `src/cnc.js` выгружает
  отверстия (`part.holes`) в DXF (контур детали + отверстия, отдельным
  блоком на деталь, открывается в CAD/CAM) и в CSV (плоский список для
  операторов).
- **Сохранение проекта**: кнопки «💾 Сохранить проект» / «📂 Открыть проект» (Ctrl+S / Ctrl+O) сохраняют/загружают весь проект файлом `.json`. Плюс автосохранение в `localStorage` браузера при каждом изменении — при случайном закрытии вкладки при следующем открытии будет предложено восстановить.
- **Эскиз → 3D через ИИ**: кнопка «📐 Эскиз → 3D (ИИ)» в шапке приложения —
  загрузка jpg/png эскиза, распознавание габаритов/секций/полок/ящиков/фасадов
  через Claude Vision, автозаполнение панели параметров с возможностью ручной
  правки.

### Как пользоваться распознаванием эскиза

1. Значок ⚙ рядом с кнопкой «📐 Эскиз → 3D (ИИ)» — вставьте туда свой
   Anthropic API-ключ (получить на console.anthropic.com → API Keys). Ключ
   сохраняется только в `localStorage` вашего браузера.
2. Нажмите «📐 Эскиз → 3D (ИИ)» — сразу откроется системный проводник/диалог
   выбора файла. Выберите фото/скан эскиза (jpg/png).
3. Появится всплывающее окно с превью — нажмите «Распознать эскиз».
4. Через несколько секунд параметры (габариты, число секций, полки, ящики,
   фасады) подставятся в панель слева — обязательно проверьте их и поправьте
   вручную, если ИИ что-то понял неточно (рукописные эскизы распознаются с
   ограниченной точностью, особенно без проставленных размеров). Эскиз может
   быть любого прямого корпусного изделия (шкаф, тумба, стеллаж и т.п.) —
   тип изделия в этом MVP не фиксирован.

**Важно про безопасность и стоимость:**
- Запрос идёт напрямую из браузера в Anthropic API — ключ виден в devtools/
  сетевых запросах. Это нормально для локального личного использования, но
  **не подходит для продакшена или общего доступа** (в реальном продукте по
  ТЗ такой вызов должен идти через ваш backend, который прячет ключ).
- Каждое распознавание — это платный запрос к API (небольшая стоимость за
  один vision-вызов, тарификация — по текущим ценам Anthropic).
- Модель может ошибаться в размерах, если они не подписаны на эскизе, и в
  сложных нестандартных секциях — рассматривайте результат как черновик.

## Доступ с других устройств (телефон, планшет, второй компьютер)

Программа — обычная статическая страница, поэтому её можно раздать по домашней
сети прямо с этого компьютера.

0. **Если `server.cmd` не запускается** и Windows пишет «Параметры безопасности
   Интернета не позволили открыть...» — снимите метку скачанного файла:
   правой кнопкой по **архиву** → Свойства → галочка «Разблокировать» → ОК,
   и распакуйте заново. Подробно — в файле `КАК-ЗАПУСТИТЬ-СЕРВЕР.txt`.
1. Запустите `server.cmd` (двойным щелчком) в папке проекта.
2. В окне будет написан адрес вида `http://192.168.1.50:8080/` — откройте его
   в браузере на телефоне или другом компьютере.
3. Устройства должны быть в одной сети Wi-Fi.
4. При первом запуске Windows спросит разрешение сети — разрешите для
   **частной** сети.
5. Закрыть окно = выключить сервер.

Порт можно задать: `server.cmd 8081`.

`server.cmd` сам выбирает, чем раздать папку: Python, затем Node, затем
встроенный сервер Windows (`server.ps1`, последнему нужны права
администратора — Windows иначе не разрешает слушать сеть).

Важно: пока сервер работает, страницу может открыть любой, кто находится в той
же сети. Проект нигде не сохраняется — у каждого устройства свой сеанс,
результат выгружается кнопками экспорта.
