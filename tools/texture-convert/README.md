# Запекание декора из листа производителя в плитку

Dev-набор, приложением не используется. Процедурная генерация жил удалена (v330) —
все декоры с рисунком рисуются одинаково: растровая плитка из реального листа
производителя в `src/decorTiles.js`, текстура накладывается на материал детали.

`bake_tile.py` берёт изображение ЦЕЛОГО листа (на странице декора на сайте Egger —
«Plattenansicht»), вырезает фрагмент по периоду повтора и ДОПОЛНЯЕТ `src/decorTiles.js`
(плитки других декоров сохраняются). Примеры команд — в шапке самого скрипта.
Исходники листов лежат вне репозитория: `D:\#Project claude\Model3D\texture-sources\`.
